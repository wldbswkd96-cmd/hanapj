# hanapj — WLF 자동 스크리닝

준법지원부 AML 담당자가 계약체결 품의서를 받을 때마다 계약업체명·대표자명을 수기로 WLF(요주의 인물/법인 리스트)에 검색하던 업무를 자동화하는 프로토타입입니다.

- 배포(아티팩트): https://claude.ai/artifact/9piCqP5CaCSRWhbbfEk7LA
- 소스: [`wlf-screening/index.html`](wlf-screening/index.html) (단일 HTML)

## 완료조건 대응

| 완료조건 | 구현 |
| --- | --- |
| AI가 계약업체명·대표자명 자동 추출 (정확도 95% 이상) | Claude가 품의서에서 업체명·대표자명(공동대표 포함)·근거 문장을 JSON으로 추출. "추출 정확도 검증" 탭에서 합성 품의서 24건(필드 48개)으로 정확도를 실측하고 95% 목표선과 비교. AI를 쓸 수 없으면 규칙 기반 추출기로 대체 |
| 수기 입력 없이 WLF 자동 조회 | 추출값을 바로 WL 명단과 매칭. 법인격 표기·공백 정규화 후 한글 자모 단위 편집거리로 유사도를 계산해 오타·띄어쓰기·별칭까지 탐지 |
| WL 매칭 위험건 즉시 알림 | 유사도 0.95 이상은 WL 일치, 0.80 이상은 유사·검토로 분류해 토스트·알림함에 즉시 표시. 다른 담당자가 등록한 품의서도 공유 저장소로 실시간 수신 |
| 불일치·검색누락 0건 관리 | 추출값이 원문에 글자 그대로 있는지 대조하고, AI와 규칙 추출 결과를 교차검증. 불일치·누락 건수를 KPI로 표시하고, 원문과 맞지 않으면 '이상 없음'으로 닫을 수 없도록 차단. 담당자 판정은 검토 이력에 남음 |

## 참고

- 예시 품의서·업체·인물과 WL 명단은 모두 **테스트용 가상 데이터**입니다.
- 운영 연동 시 `WL` 상수와 `screenName()`을 AML 시스템 WLF 임의수행 조회 API 호출로 바꾸고, 포털 수신 이벤트를 `inbox` 컬렉션 등록으로 연결하면 됩니다.
